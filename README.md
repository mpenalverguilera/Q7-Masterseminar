# Master Seminar Deliverable: Systematic Mapping Study

This repository contains the final deliverables, documentation, and data extraction sheets for the Master Seminar project: **Long Horizon Task Planning for Autonomous Agents with Hybrid Architecture**.

## 📁 Project Contents

* **Long_Horizon_Task_Planning_for_Autonomous_Agents_with_Hybrid_Architecture_a_Systematic_Mapping_Study.pdf**
  The final written report detailing the methodology, execution, and findings of the systematic mapping study.
  
* **Final Presentation**
  The slide deck utilized for the final seminar presentation.

* **Screening process**
  Detailed documentation of the paper selection phase. This includes the complete lists of included papers, as well as excluded papers alongside their specific reasons for exclusion.

* **Collection Classification**
  The core data extraction database. This file contains the extraction output for the selected papers chosen for a full read, the comprehensive mastertable for classification, and the derived schemas mapped to each Research Question (RQ).

* **Figure generation from Classification**
  The analytical spreadsheets used to calculate statistics, generate insights, and build the plots featured in the final report.
